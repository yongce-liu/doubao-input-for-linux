# v1.2.0 — 独立 deb、无 gi 依赖与尾音保护

## 主要变化

- 提供在 Ubuntu 22.04 基线上构建的独立 amd64 deb，内含 Python 和程序依赖。
  安装端不需要 uv、pip、虚拟环境或系统 gi；apt 补齐音频、剪贴板等系统组件。
- 登录改用系统 Chrome/Chromium 的独立临时会话；`login --force` 可重新登录。
- 托盘改用 D-Bus StatusNotifierItem/DBusMenu，没有托盘宿主时回退系统通知。
- 修复旧 PortAudio/ALSA 库随包分发导致 PipeWire 设备消失、录音采样率错误的问题。
- 松开 Ctrl 或点击停止后继续录音 400 ms，最终结果最多再等 2 秒，减少尾句截断。
- 删除旧 WebKit/Cairo UI、线程版 ASR 客户端、废弃探针和配置，保留单一识别路径。

## 安装

适用目标：Ubuntu 22.04 及以上，x86-64/amd64 桌面。
登录需要已安装原生 Chrome/Chromium，推荐 Google Chrome。

```bash
sha256sum -c SHA256SUMS
sudo apt install ./doubao-input_1.2.0-1_amd64.deb
```

注销桌面并重新登录，使 input 组权限生效，然后：

```bash
/usr/bin/doubao-input login
/usr/bin/doubao-input doctor
systemctl --user daemon-reload
systemctl --user enable --now doubao-input.service
```

无需再运行 `install-service`。若用图形安装器导致无法确定当前用户，需手动执行
`sudo usermod -aG input "$USER"` 并注销再登录。

## 从旧手动安装版本迁移

先执行 `systemctl --user disable --now doubao-input.service`。
备份移走 `~/.config/systemd/user/doubao-input.service` 及其 `.service.d` 覆盖目录，
并移走 `~/.local/bin/doubao-input`、`/usr/local/bin/doubao-input` 中的旧程序，
避免它们覆盖 deb 的 `/usr/bin/doubao-input`。再按上述步骤安装并启用服务。
`~/.config/doubao-input/` 中的登录和设备配置可以保留。

## 验证与限制

- 92 项自动测试通过，包含尾音、迟到最终结果、取消清理和真实 D-Bus 通信测试。
- Ubuntu 22.04 干净容器安装、权限、CLI、卸载验证通过；真实桌面的登录、
  麦克风与焦点行为仍依赖浏览器和桌面环境。
- Ubuntu GNOME 托盘需要 AppIndicator 扩展；原 `--indicator-style float` 改为通知。
- Snap/Flatpak 浏览器的隔离可能阻止独立登录会话。
- 使用豆包非官方网页接口；尾音宽限不能保证服务端识别质量或接口长期稳定。
- 本次附件仅提供 amd64 deb 和 SHA-256 校验文件，不提供 ARM 架构包。
