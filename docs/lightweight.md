# 架构与验收

## 进程与边界

- `serve`：一个 asyncio 循环管理 evdev 热键、PortAudio 采集、WSS 识别与粘贴。
  线程回调只用 `call_soon_threadsafe` 投递，不加载 GUI 库。
- `_indicator`：独立 D-Bus StatusNotifierItem/DBusMenu 进程，无宿主则用通知。
  stdin 只收固定状态，stdout 只回 `event:*`；不传识别文本、音频或凭证。
  源码和冻结版本统一通过 CLI 启动，EOF 关闭。
- `login`：主动调用时打开 Chrome/Chromium 独立临时会话，通过 CDP 获取凭证。
  已保存时复用；`--force` 重登。凭证保存成功后关闭浏览器，清理临时配置。

凭证写入 XDG 配置目录，0600 权限、原子替换。识别内容和带身份信息的 URL 不记日志。
核心服务与 `test-mic` 共用实例锁，防止抢占设备。

## 录音与识别

`idle → connecting → recording → finishing → pasting → idle`

- 小于 150 ms 的误触立即取消；最长 120 秒；队列上限 64 块。
- 每次独立 token 和队列，保留建连前的音频，旧回调不能混入下一句。
- 松开 Ctrl / 托盘点击停止后继续采集 400 ms，覆盖 256 ms 的回调分块与尾音。
  停止音频线程并处理已经排入主循环的回调后，才入队本地结束标记。
- 结束标记只控制本地发送任务：不清空队列、不发送未经验证的协议结束包。
  等服务端 finish，最多再等 2 秒，采用最后一条完整文本更新。
- 取消、错误、超时或关闭服务均清理尾音定时器；服务端提前结束时等松键再粘贴。
- 结束、等待结果和粘贴期间不接受新会话；不并行识别多句话。
- 只有确认认证错误才清除凭证。取消时收拢连接任务，退出时等粘贴线程释放虚拟按键。

## 桌面与分发

- 用户服务使用 `WantedBy=default.target`，兼容 Cinnamon/XFCE。
- `session_env.py` 从 loginctl、systemd 用户环境和 X11 socket 恢复显示环境；
  托盘启动失败时按 5→30 秒退避重试。
- `runtime_dir()` 缺少 XDG_RUNTIME_DIR 时回落到 `/run/user/<uid>`，保持单实例锁一致。
- 单文件与 deb 在 Ubuntu 22.04 基线上构建，内含 Python 及 Python 依赖。
  系统提供 PortAudio/ALSA/JACK、剪贴板工具、D-Bus 和浏览器；不携带旧音频库。
- deb 自动安装系统依赖、配置 udev 和 input 组，提供用户服务；用户登录豆包并选择自启。

## 限制

- 尾音宽限与更长等待可减少客户端截断，不保证服务器识别质量或网页接口稳定性。
- 16kHz / int16 / 单声道 / 4096 样本；不做软件重采样，优先系统 pipewire/pulse 设备。
- 麦克风编号在设备插拔后可能变化；图标表示录音状态，不保证音量非零。
- 剪贴板会被覆盖；纯 Wayland 无法查询全局焦点，自动粘贴回退 Ctrl+V。
- GNOME 托盘需要 AppIndicator 扩展；通知可能受勿扰模式影响。

## 手工验收

1. 登录成功后进程退出，下一次按键读取新凭证；重新登录失败不破坏旧凭证。
2. 连续录 10 次长短句，最后一个字说完同时松开：每次仅粘贴一次、尾句完整。
3. 托盘点击停止同样保留尾音；短按取消、尾音期间退出均不残留录音。
4. 断网时显示错误但保留凭证，重连后可再次识别。
5. `test-mic` 可收到非零音量；运行第二个服务被实例锁拒绝。
6. X11/Wayland 分别验证快捷键、终端粘贴、托盘菜单、自启及退出。
7. 新机器用 apt 安装 deb，无 uv/系统 Python 仍可运行；注销后设备权限生效。

离线单元测试与 D-Bus 通信测试不替代真实账号、音频及桌面验收。
