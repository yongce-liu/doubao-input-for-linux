# 轻量后台版设计与验收

## 实现范围

- 默认入口为 `serve`，核心进程不导入 gi、GTK、WebKit、Cairo、控制窗口或波形组件。
- 状态图标由独立辅助进程提供：X11 默认 `Gtk.StatusIcon` 托盘/Dock 常驻图标（待机灰、录音绿、处理黄、错误红，悬停有提示文本），可选 `--indicator-style float` 使用非激活、点击穿透的右下角浮标；Wayland 使用系统通知。核心通过单向管道只传递状态枚举，绝不传递识别文本/音频/凭证。无动画定时器，退出时通过 EOF 关闭辅助进程；`--no-indicator` 可禁用。
- 一个常驻 asyncio 循环管理每次识别。evdev 线程把事件投递给该循环，PortAudio 线程只投递音频块。
- 每次按键读取现有凭证和设备配置，登录后不用重启服务。
- `login` 为独立进程：只在用户主动调用时打开；成功或关闭窗口后退出。
- 托盘图标可交互：左键点击等同按下/松开右 Ctrl；右键菜单提供麦克风选择、快捷键选择（右 Ctrl / 右 Shift / 右 Alt，运行时切换）、登录、退出。事件经托盘进程 stdout 回传核心，服务用 asyncio 读取。
- `login` 已保存凭证时先询问"保持登录 / 退出登录"，退出时清空本地凭证与 WebKit 会话后才打开网页重新登录。
- 自启 unit 用 `WantedBy=default.target`（Cinnamon/XFCE 不激活 graphical-session.target）。
- systemd 用户服务的进程环境里通常没有 DISPLAY/XAUTHORITY（桌面会话稍后才导入，且进程环境是快照）。`session_env.py` 在运行时用 loginctl → systemd 用户环境 → X11 socket 三级来源解析并写回 os.environ，托盘图标与 xclip/wl-copy 都因此可用；图标进程若因会话未就绪启动失败，`VoiceService._await_display` 按 5→30 秒退避自动重挂。
- `runtime.runtime_dir()` 在缺少 XDG_RUNTIME_DIR 时回落到 `/run/user/<uid>`，避免实例锁与状态文件分裂成两份、两个服务同时抢麦克风。
- 服务/托盘/麦克风测试共用用户实例锁，避免进程之间争抢设备。
- 凭证路径沿用 `~/.config/doubao-input/asr_params.json`（支持 XDG_CONFIG_HOME）。新保存凭证原子写入、权限 0600。

## 会话状态

`idle → connecting → recording → finishing → pasting → idle`

异常进入 `error` 或 `login-required`，用户下一次按键可以重试。没有凭证或凭证过期时仅短暂显示状态图标/通知，不主动打开登录窗口。状态文件不含识别正文或 cookie。

- 小于 150ms 的按键取消，不粘贴。
- 每次会话有独立队列和 token，迟到的旧音频不能进入下一句。
- 未连接前的音频保留。松开时入队结束标记，而不是清空尚未发送的数据。
- 音频队列最多 64 块；满时取消，避免无界内存增长。
- 最大录音时间 120 秒，超限取消而不是在 Ctrl 仍按下时粘贴。
- 发送结束后等待服务端 finish 或 1 秒兜底超时，使用最后一条结果。没有未经验证地添加新的协议结束包。
- 网络错误不清除登录；确认认证错误才清除凭证。
- 结束/取消时收拢 sender/receiver 任务、关闭连接、停止录音；进程退出等待正在进行的粘贴释放虚拟按键。
- 正在结束和粘贴期间不接受新的一句；当前版本没有并行识别或多句排队。

## 尚未声称解决的问题

- 未改变 16kHz / 4096 样本的录音格式。低延迟分块应通过真实录音测量后再调整。
- 继续使用剪贴板和模拟粘贴，覆盖当前剪贴板；未实现恢复剪贴板、输入法协议注入或自动判断终端。
- 粘贴快捷键默认 auto：粘贴前读焦点窗口 WM_CLASS，终端用 Ctrl+Shift+V
  （xterm 系 Shift+Insert），其它应用 Ctrl+V。探测失败回退 Ctrl+V。
- 没有音量波形或录音提示音，只提供麦克风状态图标。图标反映录音流/处理阶段，并不保证麦克风采集到了非零音量；音量仍通过 `test-mic` 检查。
- 托盘图标基于 XEmbed `Gtk.StatusIcon`；GNOME/Wayland 默认不显示时退回系统通知，可用 AppIndicator 扩展。
- Wayland 通知可能受勿扰模式影响，不能跨所有桌面强制定位在右下角。
- 输入设备用 PortAudio 编号配置，编号不是跨插拔稳定的标识。
- 部分 ALSA 硬件不支持 16kHz 直采，需要系统 pulse/pipewire 默认设备；当前未新增重采样器。
- 不承诺服务器识别质量、网络延迟、网页接口长期稳定性，也未量化内存/CPU 节省。

## 源码与发行包

使用 uv.lock 固定 Python 依赖。GTK/WebKit 由系统提供，GTK3/Cairo 用于浮标，GTK4/WebKit 用于登录/兼容 UI，因此本地 venv 以系统 Python 加 `--system-site-packages` 建立。

源码 `install-service` 生成指向该 uv 环境的用户服务；安装 deb 则使用发行包中的 `/usr/bin/doubao-input serve`。两种部署方式不同时启用，切换时需检查 `~/.config/systemd/user/doubao-input.service`，该用户文件会覆盖发行包服务。

## 手工验收清单

1. 退出旧版，启动 `serve`：没有控制窗口、没有启动动画；录音时显示红点麦克风，松开变黄，完成隐藏；浮标不能改变输入焦点。
2. 在文本编辑器连续完成 10 次按住右 Ctrl → 说话 → 松手：每次只粘贴一次，没有窗口弹回。
3. 短按 <150ms：无粘贴，下一次正常录音仍可用。
4. 说短句并在连接完成前松手：不能因客户端清空缓冲而丢句。
5. 断网录音：有错误状态，不清除凭证、不弹登录，恢复网络后可重试。
6. 运行第二个 `serve`：应明确拒绝，不生成两个监听器。
7. 关闭 `login` 窗口：进程退出；完成登录：保存后退出，后台下一次按键可读取。已有凭证时先弹状态对话框，"退出登录"清空凭证后才进入网页登录。
11. 托盘左键点击开始/结束一次完整录音粘贴；右键菜单切换快捷键后立即生效；菜单"退出"干净停止服务。
8. SIGTERM / Ctrl+C 停服务：录音、监听器、连接和实例锁均释放。
9. 检查 systemd 自启、桌面注销后的服务停止、用户会话环境导入。
10. 分别在实际 X11 / Wayland 会话验证剪贴板与快捷键。终端另测 Ctrl+Shift+V。

自动测试使用假音频与假 WebSocket；不会代替以上真实登录、音频及桌面焦点验收。
